<code>/dubbing</code> と <code>/srt</code> スキルに関するよくある質問です。セットアップと使い方については [README](README.md) をご覧ください。

### 利用するには何が必要ですか？

**Node.js 18以上**があれば十分です。スタイル付き字幕、自分で用意したSRTの翻訳、ショートクリップはサインアップなしで使えます。サーバー側のAI処理（吹き替え・リップシンク・音声分離・音声認識）だけが Perso Dubbing APIキーを必要とします。→ [APIキーを取得](https://developers.perso.ai/api-keys)

### APIキーはどのように登録しますか？

初回実行時にブラウザのページが開きます — サインインして一度クリックするだけで、キーが発行され、このマシンに暗号化して保存されます。コピーする必要はありません。ブラウザを開けない場合は、代わりにキーファイルが開きます: そのファイルに**APIキーのみ**を貼り付けて保存してください（暗号化された後、ファイルは削除されます）。**キーをチャットに貼り付けないでください。** 手動確認: <code>npm run key:check</code>

### 料金はかかりますか？

スキルは無料・オープンソース（MIT）です。スタイル付き字幕、自分で用意したSRTの翻訳、ショートクリップは無料です。サーバー側のAI処理（吹き替え・リップシンク・音声分離・音声認識）だけがクレジットを消費し、処理した分だけの支払いです。

### 何を入力できますか？

ローカルファイル、ローカルフォルダ、またはURL（YouTube、TikTok、Google Drive）です。サイズが大きすぎる動画や非常に長い動画は自動的に分割・処理され、最後に結合されます。

### 複数言語への吹き替えや、複数ファイルの一括処理はできますか？

はい。1つのコマンドに複数言語を指定できます（<code>--target en,ja,zh</code>）— ソースのアップロードと分割は一度だけ行われ、言語ごとに再利用されます。複数のファイル・フォルダ・URLを1回の実行で混在させることもできます。

### 結果はどこに保存されますか？

デフォルトでは元の動画と同じ場所に保存されます。<code>--out</code> で指定したフォルダに保存することもできます。すべての実行結果は、Perso ポータル（<https://perso.ai/en/workspace/vt>）上のプロジェクトとしても保存され、そこから再ダウンロードしたり、他の形式を取得したりできます。

### リップシンクとは何ですか？

口の動きを吹き替え音声に同期させる機能です。吹き替えの後に実行され、動画にのみ対応し、処理時間はかなり長くなり、追加のクレジットがかかります。<code>--lipsync</code> を追加してください。

### 音声分離とは何ですか？

ソースを音声／背景音／サブ背景音のトラックに分割します — 吹き替えは行いません。<code>--separate</code> を追加してください。

### 吹き替えの代わりに字幕（SRT）を作成できますか？

**<code>/srt</code>** スキルが、Persoの音声認識（speech-to-text）を使って動画/音声/URLから元言語の字幕を抽出します。翻訳もしてほしい場合は、SRTと一緒に希望する言語を伝えてください。また、**スタイル付き字幕を動画に焼き込む**こと（既製のプリセット、または独自のフォント・色・位置）もでき、この処理はローカルで実行されるため無料です（自分で用意したSRTならキーもクレジットも不要です）。

### 途中で停止しました（クレジット切れ、クラッシュ、シェルの強制終了）。どうすればいいですか？

実行中は進捗が状態ファイルに保存され続けます（<code>/dubbing</code> の場合は <code>*.dubresume.json</code>、<code>/srt</code> の場合は <code>*.srtresume.json</code>）。表示された <code>--resume &quot;&lt;state-file&gt;&quot;</code> コマンドを再実行すると、残りの部分だけを完了できます — 完了済みの部分はスキップされ、再課金されることはありません。

### クレジットが不足しました。どうやってチャージすればいいですか？

このスキルは Stripe の支払いリンクを生成できます（プランに応じて、サブスクリプション登録・プラン変更・クレジット購入のいずれか）。リンクはご自身で開いて支払ってください — エージェントが代わりに支払うことはありません。チャージ後は、表示された <code>--resume</code> コマンドで再開してください。

### ローカルファイルを保存せずに吹き替えできますか？

はい、単一（分割されていない）動画であれば可能です: <code>--no-save</code> を追加してください。結果はPersoワークスペース内に残り、ダウンロードされません。分割された動画は、結合後のファイルをローカルにダウンロードする必要があるため、通常どおり保存されます。

### <code>node</code> が見つからないと表示されます — どうすればいいですか？

このスキルには Node.js 18以上 が必要です。<code>node -v</code> で確認してください。入っていない場合は <https://nodejs.org> からLTS版をインストールするか、エージェントにインストールを依頼してから、再試行してください。

### スキルはどうやって更新しますか？

<code>npx perso-dubbing@latest</code> を実行するか、Claude Codeプラグインでは <code>/plugin update perso-dubbing</code> を実行してください。

### スキルはどのようなデータを収集しますか？

利用イベントのみです — 実行されたアクション、成功したかどうか、概算のカウント数、アプリバージョン、OSなど — インストールごとのランダムなIDとワークスペース番号でタグ付けされます。APIキーとメディアが含まれることは一切ありません。
