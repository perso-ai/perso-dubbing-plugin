คำถามที่พบบ่อยเกี่ยวกับสกิล <code>/dubbing</code> และ <code>/srt</code> สำหรับการตั้งค่าและวิธีใช้งาน โปรดดูที่ [README](README.md)

### ต้องมีอะไรบ้างในการใช้งาน?

**Node.js 18+** คือทั้งหมดที่คุณต้องมี คำบรรยายแบบมีสไตล์ การแปลไฟล์ SRT ที่คุณจัดหามาเอง และคลิปสั้นใช้งานได้โดยไม่ต้องสมัครสมาชิก มีเพียงขั้นตอน AI ที่ทำงานบนเซิร์ฟเวอร์ (พากย์เสียง ลิปซิงก์ แยกเสียง แปลงเสียงพูดเป็นข้อความ) เท่านั้นที่ต้องใช้คีย์ API ของ Perso Dubbing → [รับคีย์ API](https://developers.perso.ai/api-keys)

### จะลงทะเบียนคีย์ API ของฉันได้อย่างไร?

ในการรันครั้งแรกจะมีหน้าเว็บเปิดขึ้นในเบราว์เซอร์ — ลงชื่อเข้าใช้แล้วคลิกเพียงครั้งเดียว คีย์ของคุณจะถูกออกให้และจัดเก็บไว้บนเครื่องนี้แบบเข้ารหัส ไม่ต้องคัดลอกอะไรทั้งสิ้น หากไม่สามารถเปิดเบราว์เซอร์ได้ ไฟล์คีย์จะเปิดขึ้นมาแทน: วาง**เฉพาะคีย์ API ของคุณ**ลงในไฟล์นั้นแล้วบันทึก (คีย์จะถูกเข้ารหัสและไฟล์จะถูกลบทิ้ง) **ห้ามวางคีย์ลงในแชทเด็ดขาด** ตรวจสอบด้วยตนเอง: <code>npm run key:check</code>

### มีค่าใช้จ่ายหรือไม่?

สกิลนี้ฟรีและโอเพนซอร์ส (MIT) คำบรรยายแบบมีสไตล์ การแปลไฟล์ SRT ที่คุณจัดหามาเอง และคลิปสั้นนั้นฟรี มีเพียงขั้นตอน AI ที่ทำงานบนเซิร์ฟเวอร์ (พากย์เสียง ลิปซิงก์ แยกเสียง แปลงเสียงพูดเป็นข้อความ) เท่านั้นที่คิดค่าใช้จ่ายเป็นเครดิต — คุณจ่ายเฉพาะตามปริมาณที่คุณประมวลผล

### ใช้ไฟล์แบบไหนได้บ้าง?

ไฟล์ในเครื่อง โฟลเดอร์ในเครื่อง หรือ URL (YouTube, TikTok, Google Drive) วิดีโอที่มีขนาดใหญ่เกินไปหรือยาวมากจะถูกแบ่ง ประมวลผล และรวมกลับเข้าด้วยกันโดยอัตโนมัติ

### พากย์เสียงหลายภาษา หรือประมวลผลหลายไฟล์พร้อมกันได้ไหม?

ได้ ใส่หลายภาษาไว้ในคำสั่งเดียว (<code>--target en,ja,zh</code>) — ต้นฉบับจะถูกอัปโหลดและแบ่งเพียงครั้งเดียว แล้วนำกลับมาใช้ซ้ำในแต่ละภาษา คุณยังสามารถผสมไฟล์ โฟลเดอร์ และ URL หลายรายการในการรันครั้งเดียวได้อีกด้วย

### ผลลัพธ์ถูกบันทึกไว้ที่ไหน?

ตามค่าเริ่มต้นจะบันทึกไว้ข้างวิดีโอต้นฉบับ หรือในโฟลเดอร์ที่คุณระบุด้วย <code>--out</code> การรันแต่ละครั้งยังเป็นโปรเจกต์ในพอร์ทัล Perso ของคุณด้วย (<https://perso.ai/en/workspace/vt>) ซึ่งคุณสามารถดาวน์โหลดซ้ำหรือขอรูปแบบไฟล์อื่นได้ที่นั่น

### ลิปซิงก์คืออะไร?

เป็นการปรับการขยับปากให้ตรงกับเสียงที่พากย์ไว้ ทำงานหลังจากการพากย์เสียง ใช้ได้กับวิดีโอเท่านั้น ใช้เวลานานกว่ามาก และเสียเครดิตเพิ่มเติม เพิ่ม <code>--lipsync</code>

### การแยกเสียงคืออะไร?

เป็นการแบ่งต้นฉบับออกเป็นแทร็กเสียงพูด / เสียงพื้นหลัง / เสียงพื้นหลังรอง — ไม่มีการพากย์เสียงเกี่ยวข้อง เพิ่ม <code>--separate</code>

### ทำคำบรรยาย (SRT) แทนการพากย์เสียงได้ไหม?

สกิล **<code>/srt</code>** จะดึงคำบรรยายภาษาต้นฉบับออกจากวิดีโอ/เสียง/URL ผ่านระบบแปลงเสียงพูดเป็นข้อความของ Perso หากต้องการให้แปลด้วย ก็เพียงขอไฟล์ SRT พร้อมระบุภาษาที่ต้องการ นอกจากนี้ยังสามารถ**ฝังคำบรรยายแบบมีสไตล์ลงบนวิดีโอ**ได้ด้วย — พรีเซ็ตสำเร็จรูปหรือฟอนต์ สี และตำแหน่งของคุณเอง — ซึ่งทำงานในเครื่องและฟรี (หากใช้ SRT ของคุณเองก็ไม่ต้องใช้คีย์หรือเครดิต)

### หยุดทำงานกลางคัน (เครดิตหมด ขัดข้อง หรือเชลล์ถูกยกเลิก) ต้องทำอย่างไร?

ความคืบหน้าจะถูกบันทึกลงในไฟล์สถานะตลอดการทำงาน (<code>*.dubresume.json</code> สำหรับ <code>/dubbing</code>, <code>*.srtresume.json</code> สำหรับ <code>/srt</code>) รันคำสั่ง <code>--resume &quot;&lt;state-file&gt;&quot;</code> ที่แสดงไว้อีกครั้งเพื่อทำเฉพาะส่วนที่เหลือให้เสร็จ — ส่วนที่เสร็จแล้วจะถูกข้ามและจะไม่ถูกคิดเครดิตซ้ำ

### เครดิตหมด จะเติมเครดิตได้อย่างไร?

สกิลสามารถสร้างลิงก์ชำระเงินผ่าน Stripe ได้ (สมัครสมาชิก เปลี่ยนแผน หรือซื้อเครดิต ขึ้นอยู่กับแผนของคุณ) คุณจะเป็นผู้เปิดลิงก์และชำระเงินด้วยตัวเอง — เอเจนต์จะไม่ชำระเงินแทนคุณ หลังจากเติมเครดิตแล้ว ให้ทำงานต่อด้วยคำสั่ง <code>--resume</code> ที่แสดงไว้

### พากย์เสียงโดยไม่บันทึกไฟล์ในเครื่องได้ไหม?

ได้ สำหรับวิดีโอเดี่ยว (ที่ไม่ได้ถูกแบ่ง): เพิ่ม <code>--no-save</code> ผลลัพธ์จะยังคงอยู่ใน workspace ของ Perso และจะไม่ถูกดาวน์โหลด ส่วนวิดีโอที่ถูกแบ่งจะยังคงถูกบันทึกตามปกติ เนื่องจากไฟล์ที่รวมแล้วจำเป็นต้องดาวน์โหลดมาไว้ในเครื่อง

### ไม่พบ <code>node</code> — ต้องทำอย่างไร?

สกิลนี้ต้องการ Node.js 18+ ตรวจสอบด้วย <code>node -v</code> ติดตั้งเวอร์ชัน LTS จาก <https://nodejs.org> หรือขอให้เอเจนต์ติดตั้งให้คุณ แล้วลองใหม่อีกครั้ง

### จะอัปเดตสกิลได้อย่างไร?

<code>npx perso-dubbing@latest</code> หรือในปลั๊กอิน Claude Code: <code>/plugin update perso-dubbing</code>

### สกิลเก็บข้อมูลอะไรบ้าง?

เก็บเฉพาะข้อมูลการใช้งานเท่านั้น — การทำงานที่รัน ว่าสำเร็จหรือไม่ ตัวนับแบบคร่าวๆ เวอร์ชันแอป และระบบปฏิบัติการ — ติดแท็กด้วย ID แบบสุ่มต่อการติดตั้งและหมายเลข workspace ของคุณ คีย์ API และเนื้อหาสื่อของคุณจะไม่ถูกรวมไว้เด็ดขาด
