## ติดตั้ง

> **เป็นเอเจนต์ที่มาติดตั้งจาก URL ของ repo นี้ใช่ไหม?** ใน Claude Code ให้รันคำสั่งนี้ได้เลย (แบบ non-interactive รันซ้ำได้อย่างปลอดภัย):
> ```bash
> claude plugin marketplace add perso-ai/perso-dubbing-plugin && claude plugin install perso-dubbing@perso-ai
> ```
> จากนั้นแจ้งให้ผู้ใช้รีสตาร์ต เพื่อให้ `/dubbing`, `/srt`, `/clip` โหลดขึ้นมา โฮสต์อื่น: `npx perso-dubbing` ไม่มีเทอร์มินัล (ChatGPT / Gemini): [chatgpt-setup](../chatgpt-setup.md) · [gemini-setup](../gemini-setup.md)

**แอป Claude เดสก์ท็อป** (แพลนแบบชำระเงิน): เปิด **แท็บ Code** เลือกโฟลเดอร์ เลือก **Local** แล้ววางคำสั่งนี้:

```text
claude marketplace add perso-ai/perso-dubbing-plugin && claude install perso-dubbing@perso-ai
```

**Claude Code CLI**: `/plugin marketplace add perso-ai/perso-dubbing-plugin` แล้วตามด้วย `/plugin install perso-dubbing@perso-ai`

**Codex · Antigravity · โฮสต์อื่น ๆ**: `npx perso-dubbing` จะตรวจหาโฮสต์ที่คุณมีและติดตั้งให้ครบทุกตัว

ต้องการแค่ **Node.js 18+** เท่านั้น ไม่ต้องมีอะไรเพิ่ม [คู่มือแบบเห็นภาพ](https://dubbing-plugin.perso.ai/en/) · [FAQ](FAQ.md)

## ซับไตเติลมีสไตล์

เลือกจากพรีเซ็ต 12 แบบ หรือแค่บรรยายลุคที่ต้องการเป็นคำพูดธรรมดา: *"ตัวหนังสือเหลือง ขอบดำ วางด้านล่าง"* การเบิร์นซับรันด้วย ffmpeg ในเครื่องของคุณเอง: ไม่ต้องอัปโหลด ไม่ต้องรอคิว ไม่ต้องมีบัญชี มีหลายภาษา? SRT แต่ละไฟล์จะได้วิดีโอฉบับสมบูรณ์ของตัวเอง

## คลิปสั้น

ใส่ไทม์โค้ดเข้าไป ได้คลิปสั้นแนวตั้งออกมา: จัดเฟรมใหม่จาก 16:9 เป็น 9:16 ตั้งชื่อไฟล์ให้ และพร้อมใส่ซับต่อทันที หรือจะส่งทรานสคริปต์มาให้ AI เลือกช่วงที่เหมาะกับคลิปสั้นก็ได้: เปิดด้วยฮุก พาไปถึงจุดพีคของรีแอ็กชัน แล้วตัดจบก่อนพลังจะตก ความยาวคลิปละ 30–90 วินาที

## พากย์เสียงและลิปซิงค์

รันครั้งเดียวรับได้ทั้งไฟล์เดี่ยว โฟลเดอร์ทั้งโฟลเดอร์ หรือ URL ของ YouTube/TikTok และพากย์เป็นหลายภาษาได้จากการอัปโหลดเพียงครั้งเดียว วิดีโอที่ยาวเกินลิมิตของแพลนจะถูกแบ่ง ประมวลผล และรวมกลับให้เองอัตโนมัติ งานที่ถูกขัดจังหวะจะรันต่อจากจุดที่หยุดพอดี โดยไม่คิดเงินซ้ำกับส่วนที่เสร็จแล้ว การพากย์จะโคลนเสียงต้นฉบับให้พูดภาษาใหม่ และลิปซิงค์จะขยับปากให้ตรงกับเสียงโคลนนั้น

## ถอดเสียงเป็นซับไตเติล (STT)

ยังไม่มีซับ? ระบบแปลงเสียงเป็นข้อความจะรันบนเซิร์ฟเวอร์ของ Perso โดยใช้เครดิต เพื่อถอดเสียงในวิดีโอออกมาเป็น SRT ภาษาต้นฉบับ ทำได้ทั้งไฟล์เดียวหรือทั้งโฟลเดอร์ และทุกขั้นตอนหลังจากมี SRT แล้วฟรีทั้งหมด: แปล จัดสไตล์ เบิร์นลงวิดีโอ

## แยกเสียง

แยกวิดีโอหรือไฟล์เสียงออกเป็นแทร็กสะอาด ๆ: เสียงพูดและเสียงพื้นหลัง ถ้ามีผู้พูดหลายคน เสียงของแต่ละคนจะออกมาเป็นแทร็กของตัวเอง จะเปลี่ยนซาวด์แทร็ก รีมาสเตอร์บทพูด หรือหยิบแทร็กไหนไปใช้แยกก็ได้

**MIT ฟรีและโอเพนซอร์ส** ทุกอย่างที่รันบนเครื่องของคุณไม่มีค่าใช้จ่ายและไม่ต้องมีบัญชี: จัดสไตล์และเบิร์นซับไตเติล แปล SRT ที่คุณมีอยู่ ตัดคลิปตามไทม์โค้ด เครดิตจะถูกใช้เฉพาะเมื่องานรันบนเซิร์ฟเวอร์ของ Perso เท่านั้น: พากย์เสียง ลิปซิงค์ แยกเสียง และถอดเสียงเป็นข้อความ คิดเงินตามวินาทีที่ประมวลผลผ่าน [Perso Dubbing API](https://developers.perso.ai/api-keys)
