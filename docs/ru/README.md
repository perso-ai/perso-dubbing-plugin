Навык (skill) для агентов программирования, который добавляет вашему агенту ИИ-дубляж от [Perso Dubbing](https://perso.ai/dubbing). Установите его один раз, а затем просто скажите *«продублируй это видео на английский»*.

- ![бесплатно](https://img.shields.io/badge/%E2%9C%93%20%D0%B1%D0%B5%D1%81%D0%BF%D0%BB%D0%B0%D1%82%D0%BD%D0%BE-2ea44f) **Стилизованные субтитры** — вшивание готовых или стилизованных субтитров в видео. **Главное в этом релизе.**
- ![бесплатно](https://img.shields.io/badge/%E2%9C%93%20%D0%B1%D0%B5%D1%81%D0%BF%D0%BB%D0%B0%D1%82%D0%BD%D0%BE-2ea44f) **Перевод субтитров** — превратите уже имеющийся SRT в любой язык
- ![бесплатно](https://img.shields.io/badge/%E2%9C%93%20%D0%B1%D0%B5%D1%81%D0%BF%D0%BB%D0%B0%D1%82%D0%BD%D0%BE-2ea44f) **Короткие клипы** — нарезка длинного видео на короткие хайлайты, переформатирование 16:9 → 9:16
- **Дубляж** на другой язык — один файл, целая папка или URL
- **Синхронизация губ** в дублированном видео, чтобы движения рта совпадали с новой озвучкой
- **Разделение** голоса и фонового звука
- **Субтитры из речи** — извлечение SRT через распознавание речи (или используйте свой → бесплатно)
- Слишком большие и очень длинные материалы автоматически разбиваются на части, обрабатываются и снова объединяются

> **Навык бесплатный и с открытым исходным кодом (MIT).** Всё, что выполняется локально на вашем компьютере, не требует **ни аккаунта, ни кредитов** — вшивание стилизованных субтитров в видео, перевод уже имеющегося SRT и нарезка коротких клипов. ИИ-шаги, выполняемые на серверах Perso — дубляж, синхронизация губ, разделение голоса и фона, распознавание речи — используют кредиты Perso Dubbing API (**платите только за то, что обрабатываете**).

Работает на **Node.js 18+**. Бесплатные шаги никогда не требуют ключа; серверные ИИ-шаги используют **API-ключ Perso Dubbing**. Построен на стандарте Agent Skills (`SKILL.md`), поэтому ведёт себя одинаково в Claude, Codex и Antigravity.

## Установка

> 📖 **[Наглядная инструкция →](https://dubbing-plugin.perso.ai/en/)** — выберите агента и скопируйте команды.

### Приложение Claude для компьютера — проще всего, без терминала (около 3 минут)

В <a href="https://claude.ai/download" target="_blank" rel="noopener noreferrer">приложении Claude для компьютера</a> (платный план):

1. Откройте **вкладку Code** (по центру сверху), выберите любую папку и укажите окружение **Local** — в облачных сессиях плагины не работают.
2. Вставьте эту команду в поле ввода и нажмите Enter:

   ```text
   claude marketplace add perso-ai/perso-dubbing-plugin && claude install perso-dubbing@perso-ai
   ```

3. Попросите продублировать видео — *«Продублируй это видео на английский — C:\videos\clip.mp4»*. URL с YouTube или папка тоже подойдут. Если не указать `--out`, результаты сохраняются рядом с исходным видео.

**Claude Code CLI:** используйте вместо этого `/plugin marketplace add perso-ai/perso-dubbing-plugin` и `/plugin install perso-dubbing@perso-ai`.

### Все остальные хосты

```bash
npx perso-dubbing
```

Определяет, какие хосты у вас есть, устанавливает оба навыка в каждый из них и выводит, куда именно попал каждый. Добавьте `--claude` / `--codex` / `--antigravity` для одного хоста, `--all` для всех сразу или `--project` только для текущего проекта. Репозиторий уже клонирован? `node scripts/install.mjs` из корня репозитория делает то же самое, без обращения к сети.

### Первый запуск — ваш API-ключ

Ключ нужен только тогда, когда действие использует API Perso (дубляж, синхронизация губ, разделение, извлечение SRT) — офлайн-шаги, такие как вшивание стилизованных субтитров в локальное видео или перевод предоставленного вами SRT, никогда его не запрашивают. Когда он нужен, откроется страница в браузере: войдите и нажмите одну кнопку — ключ будет выпущен и сохранён на этом компьютере в зашифрованном виде. Ничего копировать не нужно. Если браузер открыть не удаётся, вместо этого откроется файл ключа — вставьте туда ключ и сохраните, после чего он шифруется, а файл удаляется.

<a href="https://developers.perso.ai/api-keys" target="_blank" rel="noopener noreferrer">Получить API-ключ</a> · проверить в любой момент можно командой `npm run key:check`

## Использование

Просто скажите агенту, что вам нужно:

> «Продублируй это видео на английский — C:\videos\clip.mp4»
>
> «Продублируй все видео в этой папке на японский и испанский»
>
> «Продублируй эту ссылку с YouTube на английский, с синхронизацией губ»
>
> «Раздели голос и фоновую музыку в этом ролике»
>
> «Сделай мне английские субтитры SRT для этого видео»
>
> «Добавь стилизованные субтитры к этому видео — вот SRT»
>
> «Нарежь это видео с 2:00 до 3:00 в короткий клип»

Либо введите **`/dubbing`** / **`/srt`**, чтобы начать. Полный список опций CLI можно узнать у агента или командой `npm run dub -- --help`.

## Решение проблем

Остались вопросы? См. **[FAQ](FAQ.md)**.

| Симптом | Решение |
|---|---|
| `node` не найден | Установите LTS-версию с <a href="https://nodejs.org" target="_blank" rel="noopener noreferrer">nodejs.org</a> (или попросите агента: *«установи Node.js за меня»*), затем повторите попытку. |
| Приложение Claude для компьютера запрашивает Git (Windows) | При первом использовании вкладке Code нужен <a href="https://git-scm.com/downloads/win" target="_blank" rel="noopener noreferrer">Git для Windows</a>. Установите его и перезапустите приложение. |
| Команды `claude` или меню Plugins не реагируют | Вы находитесь в **облачной сессии** — плагинам нужна сессия **Local** (или SSH). |
| Ключ отклонён или отсутствует | Зарегистрируйте его заново: `node skills/dubbing/scripts/connect.mjs`. Проверить сохранённый ключ можно командой `npm run key:check`. |
| Ошибка, связанная с ffmpeg | Обычно ffmpeg устанавливается сам; если это не удалось, выполните `npm run doctor`. |
| Останавливается на середине (кончились кредиты, сбой, процесс завершён) | Прогресс сохраняется непрерывно. Выполните команду **`--resume "<state-file>"`**, указанную в уведомлении, — уже готовые части пропускаются и повторно не тарифицируются. |

## Конфиденциальность и телеметрия

`/dubbing`, `/srt` и `/clip` отправляют анонимные события использования, чтобы улучшать навыки — какое действие выполнено и с каким результатом, длительность медиафайла, выбор стиля, приблизительную локаль, версию приложения/ОС, а также использовался ли ключ API Perso (и зарегистрирован ли он). Каждое событие содержит случайный идентификатор установки и номер вашего рабочего пространства; никогда — ваш ключ, медиафайлы, имена файлов или текст субтитров. Отключить можно через `PERSO_NO_TELEMETRY`.
