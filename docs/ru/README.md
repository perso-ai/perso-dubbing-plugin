## Установка

> **Вы агент и устанавливаете по URL этого репозитория?** В Claude Code выполните это прямо сейчас (неинтерактивно, повторный запуск безопасен):
> ```bash
> claude plugin marketplace add perso-ai/perso-dubbing-plugin && claude plugin install perso-dubbing@perso-ai
> ```
> Попросите пользователя перезапуститься, чтобы загрузились `/dubbing`, `/srt`, `/clip`. Другие хосты: `npx perso-dubbing`. Без терминала (ChatGPT / Gemini): [chatgpt-setup](../chatgpt-setup.md) · [gemini-setup](../gemini-setup.md)

**Десктопное приложение Claude** (платный план): откройте вкладку **Code**, выберите папку, выберите **Local** и вставьте:

```text
claude marketplace add perso-ai/perso-dubbing-plugin && claude install perso-dubbing@perso-ai
```

**Claude Code CLI**: `/plugin marketplace add perso-ai/perso-dubbing-plugin`, затем `/plugin install perso-dubbing@perso-ai`

**Codex · Antigravity · всё остальное**: `npx perso-dubbing` сам определяет ваши хосты и устанавливается в каждый.

Требуется только **Node.js 18+**, больше ничего. [Наглядное руководство](https://dubbing-plugin.perso.ai/en/) · [FAQ](FAQ.md)

## Стилизованные субтитры

Выберите один из двенадцати пресетов или просто опишите вид своими словами: *«жёлтый текст, чёрная обводка, внизу».* Вшивание выполняется локально на ffmpeg: без загрузки, без очереди, без аккаунта. Несколько языков? Каждый SRT получает своё готовое видео.

## Перевод субтитров

Передайте любой SRT и назовите нужные языки. Можно несколько сразу: один проход покрывает все. Каждая строка сохраняет точный исходный тайминг, появляясь и исчезая в те же моменты, что и раньше. Перед выдачей результат проверяется на строки, которые слишком длинны или читаются слишком быстро.

## Короткие клипы

Таймкоды на входе, вертикальные шортсы на выходе: перекадровка 16:9 → 9:16, готовые имена файлов, всё подготовлено для субтитров. Или передайте расшифровку, и ИИ сам выберет моменты, которые сработают как шортсы: открывается хуком, доводит реакцию до пика, обрывается до спада энергии. По 30–90 секунд каждый.

## Дубляж и липсинк

Один запуск принимает файл, целую папку или ссылку YouTube/TikTok и с одной загрузки дублирует на несколько языков. Видео сверх лимита плана само разбивается, обрабатывается и склеивается обратно; прерванный запуск возобновляется ровно с места остановки и никогда не списывает оплату за готовые части повторно. Дубляж клонирует оригинальный голос в новый язык, а липсинк подстраивает движения губ под эту клонированную озвучку.

<sub>PERSO API</sub>

## Субтитры из речи (STT)

Субтитров ещё нет? Распознавание речи работает на серверах Perso и использует кредиты, превращая аудио видео в SRT на исходном языке: для одного файла или целой папки. Каждый шаг после появления SRT бесплатен: перевод, стилизация, вшивание.

<br>

<sub>PERSO API</sub>

## Разделение голоса

Разделяет видео или аудио на чистые дорожки: голос и фон. Если говорящих несколько, голос каждого выходит отдельной дорожкой. Замените саундтрек, отремастерьте диалоги или используйте любую дорожку отдельно.

## Бесплатно везде, где можно. Платно только там, где иначе нельзя.

**MIT, бесплатно и с открытым исходным кодом.** Всё, что выполняется на вашей машине, ничего не стоит и не требует аккаунта: стилизация и вшивание субтитров, перевод уже имеющегося SRT, нарезка клипов по таймкодам. Кредиты нужны только тогда, когда задача выполняется на серверах Perso: дубляж, липсинк, разделение голоса и распознавание речи, с оплатой за каждую обработанную секунду через [Perso Dubbing API](https://developers.perso.ai/api-keys).

Никаких церемоний с настройкой. При первом запуске серверной задачи открывается браузер: вход, один клик, ключ сохраняется в зашифрованном виде. Бесплатные шаги не спрашивают ничего.

Каждое событие содержит случайный ID установки и номер вашего воркспейса, но никогда не содержит ваш ключ, медиафайлы, имена файлов или текст субтитров. Отключается через `PERSO_NO_TELEMETRY`.</sub>
